# RAG Ollama + FAISS

Entrega de la Universidad de Antioquia realizada por Carlos David Buitrago y Daniel Mesa Patiño.

El proyecto utiliza RAG (Generación Aumentada por Recuperación) para consultar el PDF sobre el desastre aéreo de Tenerife. El notebook carga y divide el documento, crea una base vectorial con FAISS, busca el contexto más relevante y utiliza Ollama para generar una respuesta basada en esa información.
